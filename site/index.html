Everything in one place

Write code, draw the art, make the sounds, build the game or the app, and ship it, without leaving Aether.

Every language, every file

Over 100 languages coloured with nothing to install, language servers in one click, and Word, Excel, PDF, SQLite, ZIP, fonts, audio and video open right in the editor.

Game engine

A scene editor with Play, 2D and 3D starters, and Python and C++ runtimes that load your sprites and reload them live.

Art Studio

Paint with soft brushes and pen pressure, or draw vector shapes that stay sharp. Then give your art bones and animate it.

Pixel Studio

Pixel art with layers, many animations per sprite and onion skin, exported as a GIF or a sprite sheet.

Sound Studio

Make songs from tracks on a piano roll, and game sound effects from scratch. Your games play them, and they export as WAV.

App Maker

Put an app together from parts and a little code, then build a Windows .exe or an Android .apk. No other tools needed.

Aether Script

Aether's own language: easy like Python and made for games. It runs in Play, in the games you export, and on phones.

Desktop pets

A cat, a dog, a fox and more walk in along the status bar, nap and peek in. Pet them, carry them, or make your own.

Extensions

Add commands, tabs, languages, themes and pets with a few lines of JavaScript, or install them from the Aether Marketplace in one click.

Get Aether

Aether is free, under the MIT license.

  1. DownloadThe Windows installer, Aether-Setup-<version>.exe, from the releases page.
  2. InstallRun it. It adds Aether to the Start menu and the desktop, and Open with Aether to Explorer's right-click menu.
  3. Open a folderThen open any file in it. Press Ctrl+Shift+X for extensions.
Download for Windows The source on GitHub

Or build it yourself with Node.js:

npm install npm run dist

The installer lands in dist/. npm start runs Aether without installing it.
