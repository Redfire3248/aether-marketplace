# Keyboard shortcuts

Every shortcut can be changed: **Help > Keyboard Shortcuts** (**Ctrl+Alt+K**) lists them all, with a search. Click **+** and press keys to add one, **×** to remove it, and **↺** to go back to the default. It shows the code editor's and Pixel Studio's keys too.

On a Mac, **Ctrl** is **Cmd**.

## File

| | Keys |
|---|---|
| New File | `Ctrl+N` |
| New Untitled Scratch File | `Ctrl+Alt+N` |
| Rename | `F2` |
| Open File | `Ctrl+O` |
| Open Folder | `Ctrl+Alt+O` |
| Save | `Ctrl+S` |
| Save As | `Ctrl+Shift+S` |
| Save All | `Ctrl+Alt+S` |
| Close Editor | `Ctrl+W` or `Ctrl+F4` |
| Reopen Closed Editor | `Ctrl+Shift+T` |

## Studios

- **Art Studio**: **K** cut tool; the mouse wheel changes numbers in the tool bar.
- **PDF editor**: **E** edit text, **M** move things.
- **GUI Studio**: see [its shortcuts](gui.md#shortcuts).
- **Pixel Studio**: in **Keyboard Shortcuts**, under Pixel Studio.
- **Game engine**: **F2** renames a node; in 3D, **[** and **]** turn a model.
