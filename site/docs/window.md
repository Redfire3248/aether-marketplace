# The window

## The parts

- **The dock** (the strip of buttons on the left): one button for each tool: Files, Search, Git, Outline, TODOs, AI, Web, Engine, Apps, SFX (Sound Studio), Ext (extensions), GUI, Art, Images (AI pictures), PDF, Arduino, Stats (your progress) and Settings. Right-click it to hide buttons or their labels, or use the command **Customize Dock Buttons**.
- **The sidebar**: the Explorer (your files), Search, Source Control (Git), Outline (the parts of the open file) and TODOs. **Ctrl+B** shows or hides it.
- **The tabs and editors** in the middle. Every file and every tool opens in a tab.
- **The panel** at the bottom: the terminal, Problems and the Debug panel. **Ctrl+`** shows or hides it.
- **The status bar** along the bottom: line and column, language, formatter, language server, encoding, line endings, theme and more. Click an item to change it. **Settings > Tabs & dock** chooses which items show.

**Ctrl+F6** moves to the next part of the window, **Ctrl+Shift+F6** to the one before. The dock, tabs and file tree also work with the arrow keys.

## The start screen

With no file open you see the start screen: start something new, your recent folders, what Aether opens, shortcuts and a small game to play. The command **Customize Start Screen** picks which cards show.

## Commands

**Ctrl+Shift+P** (or **F1**) opens the command palette: type a few letters of anything Aether can do and press Enter. Each command shows its shortcut.

**Ctrl+P** goes to a file by name. In the same box, type `:` and a number to go to a line, or `@` for a part of the file.

## Tabs

- **Ctrl+Tab** and **Ctrl+Shift+Tab** go to the next and the previous tab. **Ctrl+Alt+W** lists every open tab.
- **Ctrl+W** closes a tab; **Ctrl+Shift+T** opens the one you just closed.
- Right-click a tab to pin it, close the others, close the ones to its right, or close the saved ones.
- Tabs can be coloured by language, and you can keep only so many open (**Settings > Tabs & dock**).
- Drag a tab to move it.

## Side by side

- **Ctrl+\\** opens the tab to the side. The **Split** commands open it on the left, right, above or below, or make four panes (2 x 2).
- **Ctrl+Shift+Left / Right / Up / Down** moves the pane you are in.
- **Split: Close All Panes** goes back to one.

## Focus

- **Ctrl+Alt+Z**: Zen mode, only the code.
- **F11**: full screen.
- **Ctrl+=**, **Ctrl+-** and **Ctrl+0**: make everything bigger, smaller, or the normal size. **Settings > Fonts & size** sets the interface size and the editor font.

## Aether remembers

Close Aether and open it again: your folder, tabs, splits, pinned tabs, tool tabs and unsaved work come back. Unsaved sprites are kept as drafts.

## Getting help

The **Help** menu has the Welcome page, **Keyboard Shortcuts** (**Ctrl+Alt+K**), the Aether Script guide, this website, Check for Updates and What's New. The commands **How Debugging Works** and **How to Make an Aether Extension** open those guides.

Click the Aether logo at the top left to see every menu at once.
