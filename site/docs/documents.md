# PDFs and other files

Aether opens almost any file. What it can't show as text, it shows in its own viewer.

## The PDF editor

Open a PDF to read it in Aether's viewer, or click **PDF** in the dock (**Create > Edit a PDF**) to change it.

- **Edit text** (**E**): every line on the page gets a light outline. Click one and type. It keeps the words' size, place, font and colour. When you save, the old words really go and yours take their place, in the PDF's own font when it has every letter.
- **Scanned pages**: Edit text offers **Read the text on this page**. Each line it finds can then be edited. (Its language file downloads once.)
- **Move things** (**M**): pick the PDF's own pictures and shapes, then drag, resize or delete them.
- **Add**: text, highlights, drawing, white-out, boxes, pictures and signatures.
- **Pages**: rotate, delete, put in a new order, add pages, and merge PDFs.
- **Forms**: fill them in.
- **Ctrl+Z** undoes; **Save PDF** saves.

## Other files

- **Pictures**: zoom, and open them in Art Studio, Pixel Studio or the picture tools (see [Art Studio](art.md#picture-tools)).
- **Sound**: Aether's player, with a waveform and Loop (see [Sound Studio](sound.md#playing-sounds)).
- **Video**, **fonts** (every letter, at any size).
- **Word** documents and **spreadsheets** (Excel and CSV).
- **SQLite** databases: browse the tables and run SQL.
- **ZIP** archives: see what is inside.
- **Anything else**: a hex view of its bytes.

## Markdown and web pages

A Markdown or HTML file opens as code. **Ctrl+Shift+V** shows it rendered beside the code, and changes as you type.
