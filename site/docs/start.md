# Aether Docs

Aether is a code editor for everything. It opens every language and almost every file, and it comes with its own tools: a game engine, Art Studio, Sound Studio, GUI Studio, Particle Studio, an App Maker that makes Windows and Android apps, Arduino with circuits you can simulate, a PDF editor, its own language (Aether Script), AI, and pets that visit your window.

Everything is in one program, with nothing else to install.

## New to Aether?

1. [Install Aether](install.md), then open it.
2. Read [The window](window.md) to find your way around.
3. Open a folder (**Ctrl+Alt+O**) and a file, and press **F5** to run it. See [Running code](run.md).

Lost? Press **Ctrl+Shift+P** (or **F1**) in Aether and type what you want to do. Every command is there, with its shortcut.
