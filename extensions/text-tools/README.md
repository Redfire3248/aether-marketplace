# Text Tools

Change case (camelCase, snake_case, Title Case and more), and sort, clean up, number or join lines.

Select text, then open the Command Palette (Ctrl+Shift+P) and type **Text:**, or press **Ctrl+Alt+X** for the list.

- **Case:** UPPER, lower, Title, Sentence, camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE.
- **Lines** (the selected lines, or the whole file): sort A to Z, Z to A or by length, remove repeated or empty lines, reverse, shuffle, trim the ends, number them, join them.
