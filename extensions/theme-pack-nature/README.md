# Nature Theme Pack

Five dark themes from the outdoors in one: Forest Night, Deep Sea, Arctic Night, Ember and Blood Moon.

| Theme | Looks like |
| :-- | :-- |
| **Forest Night** | Dark and quiet, deep greens with mint. |
| **Deep Sea** | Dark and calm, deep blues with teal. |
| **Arctic Night** | Cold and clear: midnight blue with icy light. |
| **Ember** | Dark and warm, browns with a glowing orange. |
| **Blood Moon** | Dark and dramatic: black-red with a burning crimson. |

After installing, press **Ctrl+Alt+T** (or open **Settings > Theme**) and look in the **Nature** pack.

Each theme is also in the Marketplace on its own, if you only want one of them. Needs Aether 1.9.28 or newer.
