# Theme Pack

Five colour themes: Deep Sea, Ember and Forest Night (dark), Paper and Glacier (light), easy to read all day.

Open the theme picker (Command Palette, Ctrl+Shift+P, then **Theme**, or **Theme Pack: Pick a Theme**) and pick one.

| Theme | | |
| --- | --- | --- |
| **Deep Sea** | dark | deep navy with sea green and soft blue |
| **Ember** | dark | warm brown-black with orange and gold |
| **Forest Night** | dark | dark green with mint and lime |
| **Paper** | light | warm cream paper with rust and ink blue |
| **Glacier** | light | cool white-blue with a clear blue |

Each theme colours the whole of Aether (the panels, the borders, the buttons and messages) as well as the code.

Every colour is checked to be easy to read: the text is at least 7 times the contrast of what it sits on, and code colours, buttons and messages at least 4.5 times (the WCAG levels for reading).
