# Light Theme Pack

Five calm light themes in one: Glacier, Lavender Mist, Matcha, Mint Cream and Paper.

| Theme | Looks like |
| :-- | :-- |
| **Glacier** | Light and cool, crisp blues and greys. |
| **Lavender Mist** | Light and soft: pale purple with deep violet ink. |
| **Matcha** | Calm and light: creamy green tea with deep leaf green. |
| **Mint Cream** | Light and fresh, soft greens. |
| **Paper** | Light and warm, like a page in a book. |

After installing, press **Ctrl+Alt+T** (or open **Settings > Theme**) and look in the **Light** pack.

Each theme is also in the Marketplace on its own, if you only want one of them. Needs Aether 1.9.28 or newer.
