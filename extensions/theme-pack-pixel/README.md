# Pixel Theme Pack

Six square-pixel themes in one: Amber, Cherry, Mint, Paper, Sunset and Vapor.

| Theme | Looks like |
| :-- | :-- |
| **Pixel Amber** | An old amber monitor: warm glowing orange on black. |
| **Pixel Cherry** | Square pixels with a bite: dark red with cherry pink. |
| **Pixel Mint** | Square pixels, cool and clean: deep teal with bright mint. |
| **Pixel Paper** | Square pixels on a light page: cream with bold ink. |
| **Pixel Sunset** | Square pixels at dusk: deep purple with orange and pink. |
| **Pixel Vapor** | Square pixels, loud and pink: hot pink and cyan on indigo. |

After installing, press **Ctrl+Alt+T** (or open **Settings > Theme**) and look in the **Pixel** pack.

Each theme is also in the Marketplace on its own, if you only want one of them. Needs Aether 1.9.28 or newer.
