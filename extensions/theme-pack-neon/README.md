# Neon Theme Pack

Four bright night themes in one: Neon Tide, Cyber Noir, Tokyo Rain and Plum Dusk.

| Theme | Looks like |
| :-- | :-- |
| **Neon Tide** | Dark and bright, glowing teal and pink. |
| **Cyber Noir** | Black and electric yellow, straight out of the future. |
| **Tokyo Rain** | City lights in the rain: deep indigo with neon signs. |
| **Plum Dusk** | Dark and soft, deep purples with pink. |

After installing, press **Ctrl+Alt+T** (or open **Settings > Theme**) and look in the **Neon** pack.

Each theme is also in the Marketplace on its own, if you only want one of them. Needs Aether 1.9.28 or newer.
