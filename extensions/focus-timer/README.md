# Focus Timer

Focus in blocks with breaks between, from the status bar. It chimes at the end and counts your blocks for the day.

Click **Focus** in the status bar and pick a focus block (25 minutes) or a break (5 or 15). It counts down there; click it to pause or stop. When a block ends it chimes and shows how many you did today.

Change the minutes with **Change the minutes…** in the same list.
